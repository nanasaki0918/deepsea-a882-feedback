# 深海觉醒 A882-L14 反馈仓库

本仓库仅用于收集 A882-L14 修正版的 Bug 反馈、复现步骤和版本记录。

## 当前测试版本

- 版本：`1.1.0.0 / A882-L14`
- 发布形态：Android 离线测试包
- 测试包：不在本仓库托管
- 当前已知边界：舰娘个人页语音与字幕可能提前中断；全新 Android 安装和从零账号流程仍需单独验收。

## 提交 Bug 前请提供

1. 修正版号和安装方式；
2. 设备或模拟器型号、Android 版本；
3. 是否新账号；
4. 从进入页面到出现问题的完整操作顺序；
5. 是否可以稳定复现；
6. 截图或录屏；
7. 脱敏后的相关日志片段。

请不要在 Issue 中上传 APK、OBB、账号存档、登录凭据、设备唯一标识或完整未脱敏日志。
