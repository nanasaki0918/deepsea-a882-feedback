## 签名与公开分发安全

- 当前测试包使用 Debug 测试签名，不代表正式发行证书。
- 正式 release keystore、私钥、alias 密码和其他签名凭据不会上传到本仓库，也不会随安装包分发。
- 不要在 Issue、Pull Request、网盘链接或截图中公开 keystore、密码、账号存档或登录凭据。
- 不同签名的 APK 不能直接覆盖安装；遇到安装问题前请先备份本地进度，不要贸然卸载或清除应用数据。

## 提交 Bug 前请提供

1. 修正版号和安装方式；
2. 设备或模拟器型号、Android 版本；
3. 是否新账号；
4. 从进入页面到出现问题的完整操作顺序；
5. 是否可以稳定复现；
6. 截图或录屏；
7. 脱敏后的相关日志片段。

请不要在 Issue 中上传 APK、OBB、账号存档、登录凭据、设备唯一标识或完整未脱敏日志。
